Alien Base Defense Game Prototype

How to run:
1. Extract the ZIP file.
2. Open index.html in Chrome or Edge.
3. Choose Easy, Normal, or Hard.

Controls:
- Move: W A S D
- Look: Mouse
- Fire: Left mouse click
- Sprint: Left Shift
- Reload: R
- Jump: Space

Note:
This prototype uses Babylon.js from CDN, so internet is required when opening the HTML file.
